# عينات تقييم حقيقية

ثلاثة نصوص عامة من قناتي الملابس المرتبطتين داخل كل ملف، جُمعت في 29 أكتوبر 2026. لم تُسجل هذه القنوات تلقائيًا كمصادر للبوت. لا تحتوي العينات على أسرار أو بيانات قنوات خاصة.

أسعار القطعة المرجعية 75 و35 جنيه؛ عينة 450/485 يجب أن تتوقف للمراجعة بسبب اختلاف شروط الشراء. لا تتضمن العينات صورًا، ويمكنك إضافة صورك داخل هذا المجلد والإشارة إليها بحقل `image` لاختبار الرؤية. لا تنشر أي عينات خاصة في Git؛ احتفظ بمجلد محلي خارج المستودع واستخدمه مع أداة التقييم.
